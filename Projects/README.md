# Tuesday App - FIT2101

## How to compile this project

To run the development server, run
```
npm install // if not already done
npm run start
```

To build an optimised version of the code, run
```
npm run build
```

To see an example of the dashboard used in this project, see [this link.](https://mui.com/material-ui/getting-started/templates/)

For more information on Material UI, refer to the [MUI Core](https://mui.com/material-ui/getting-started/overview/) documentation (for most features) or the [MUI X](https://mui.com/x/introduction/) documentation for information on the DataGrid / range pickers.
